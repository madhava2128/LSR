# LSR Nutrition Club (LNC)

Official web application for **LSR Nutrition Club (LNC)** — providing personalized nutrition guidance, wellness coaching, and sustainable healthy habits with Senior Wellness Coach **Siva Gangadhar Reddy**.

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org) (App Router)
- **Internationalization**: [next-intl](https://next-intl-docs.vercel.app) (English, Telugu)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion & GSAP
- **Icons**: Lucide React

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
